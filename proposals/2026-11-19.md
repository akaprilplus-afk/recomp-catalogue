## 1. PlayStation 4 "native runtime" ports: include them?

Most PS4 PC ports work differently from the recompilations already in RECOMP. The PS4 uses the same kind of processor as a PC, so these projects run the game's own original program directly and replace the PS4's system parts and graphics (mostly built on shadPS4's graphics code and the "bbport" Bloodborne runtime). They are not static recompilations and not decompilations, so they don't clearly fit the "what counts" rule. They do run natively on Windows with your own copy, and they're the main kind of PS4 PC port.

Should RECOMP include them? If yes, these were found today (all confirmed on GitHub, all have Windows builds):
