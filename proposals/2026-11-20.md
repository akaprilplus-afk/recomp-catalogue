# Proposals — 2026-11-20

Nothing in this file has been applied (except where it says "already marked"). Each item needs the owner's yes or no.

Still open from earlier files: roughly 40 items in `2026-11-18.md` and `2026-11-19.md` (including the PS4 "native runtime" question and the Ninja Gaiden II replacement).

Note: the recomp.fyi feed (https://recomp.fyi/feed.xml), allrecomps.com and recomp.gg could not be read today (the page fetches were refused), so new projects were found through a GitHub search for repositories created since 18 November, plus web searches.

## 1. Replacements found for unavailable projects

- **Ninja Gaiden II (Xbox 360)** — a second candidate besides yesterday's gamboozino/ng2recomp: https://github.com/Piscacho/Ninja-Gaiden-2-PC (`v1.0.0`, Windows 10/11, DirectX 12, Spanish README). It has a Windows download, Xbox and PlayStation controller support, and Mission Mode with the title update. Better than gamboozino's: a ready download and more features. Behind: brand new (one release), and it makes no claim about how far the game has been played. Use one of them as the main project?
- **007: Quantum of Solace (Xbox 360)** — https://github.com/thegh0sts/007-QOS-X360-PORT, a new PC recompilation of the same game (made with ReXGlue). It has no README or release yet, so I can't say how well it plays. Use it as the replacement, or wait?
- **Tekken 3 (PS1)** — https://github.com/szczuru/Tekken3Recomp (`v1.0`, "recompiled using psxrecomp") and https://github.com/FishB0nes98/Tekken3Recompiled (`v0.1.4`, "hybrid recompilation preview"). Not yet read in detail. Check one as a replacement?
- **Tekken (PS1)** — https://github.com/frknue/tekken-recomp (`v0.2.4`) says "Classic Tekken as native Windows x64 programs with rollback online play"; it may cover Tekken 1. Not yet read in detail.
- **Harvest Moon: Back to Nature (PS1)** — https://github.com/d4rksp4rt4n/HMBTN-ReFarmed (`v1.9.5`, "native PC game", widescreen, 60 fps) and https://github.com/GabrielBigardi/HarvestMoonBTN-Recomp (native Windows/Linux by static recompilation, no releases). Not yet read in detail.
- **Soul Blade (PS1)** — the catalogue already has an alternate, https://github.com/drproteus/soul-blade-recomp (`v0.0.2`). Make it the main project now that the old one is gone?
- **Call of Duty: Black Ops (Xbox 360)** — https://github.com/LucioXerus/bo1-recomp ("unofficial PC port of the Xbox 360 version", no releases). Not yet read in detail.
- **TimeSplitters (PS2)** — https://github.com/s070808/Timesplitters (`v1.0`, "a recomp of the PS2 game Timesplitters"). Not yet read in detail.

Swap?
